04 // SECURITY ARCHITECTURE

Protection Layers

Wireless security involves multiple defensive layers working together.

01

Authentication

Verifies whether a user or device is permitted to access a network.

02

Encryption

Helps protect information transmitted through a wireless connection.

03

Access Control

Restricts network resources according to permissions and security policies.

04

Monitoring

Helps administrators identify unusual or unexpected security events.

05

Updates

Keeping firmware and software updated helps address known security issues.

06

User Awareness

Users should recognize suspicious networks and unsafe wireless practices.
